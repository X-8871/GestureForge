# 阶段一实施步骤、决策与最终产物

本记录是阶段一「PC 模型与数值规格」的最小可恢复入口。它只记录已经核对后的当前状态、实施顺序、关键决策和最终产物；过程中的 review 对话、失败重试、预检日志、重复报告和临时文件不作为交付物保留。

## 1. 当前状态

- 阶段一 PC 范围已冻结；本窗口没有重新训练，也没有进入阶段二。
- Wong 已确认 tiny320、tiny416、full608 三个模型通过网页/摄像头人工测试。该事实证明三模型人工可用性，但没有指定样本数，因此不替代正式 mAP 报告。
- tiny416 是当前唯一完成官方 HaGRID test 正式数值测量的模型：25,484 张图，mAP@0.5=`0.9774176565`，mAP@0.5:0.95=`0.7700877728`，五类最小 precision=`0.9479207151`，最小 recall=`0.9701880752`。
- 三模型 PC 本体性能已经按 100 次 warmup + 1000 次有效样本测量；full608 只作 PC 对照。
- 板上 Vivado 资源/时序、板上性能和整网 INT8 检测下降没有在阶段一伪称通过，保留为后续集成进入条件。

## 2. 冻结决策

| 步骤 | 决策 | 冻结结果 |
|---|---|---|
| 1. 任务范围 | 目标为五类带框手势检测，不沿用停用的 32×32 分类规格 | `fist`、`palm`、`one`、`two_up`、`three` |
| 2. 模型角色 | tiny320、tiny416 为上板候选，full608 仅 PC 对照 | 三个独立模型 ID 和只读权重路径 |
| 3. 数据来源 | 主来源使用官方 HaGRID；当前 manifest 不扩造未审计的 robustness 集 | manifest 158,680 行，SHA-256 `fd60e7a67161f242276a1b97b09ad07c0d7f41d30067266bb99620abe6d7ed74` |
| 4. `no_hand` | 不作为阶段一阻断项，也不是第六类；官方 `no_gesture` 不改名 | 保留为网页可选诊断，不计入五类准确率 |
| 5. 浮点门槛 | mAP@0.5≥0.90；mAP@0.5:0.95≥0.70；每类 precision/recall≥0.90 | tiny416 官方 test 已通过 |
| 6. 固定推理 | score threshold=`0.25`、NMS IoU=`0.45`、每图最多 15 框 | test 和网页人工测试不再调参 |
| 7. INT8 保留门 | 相对浮点 mAP@0.5 和逐类 recall 的绝对下降均≤5个百分点，且 D2 溢出规则满足 | 规则冻结；整网检测下降本轮未测，不阻断 PC 范围冻结 |
| 8. D3 范围 | 阶段一只测 PC 模型本体；100 warmup + 1000 valid | 板上 LUT/FF/BRAM/DSP≤85%、WNS/WHS≥0、TNS/THS=0 保留到阶段 2A |
| 9. 回滚 | 网页注册表绑定 cfg/data/weights 和 SHA；切换注册表即可回滚 | 不覆盖外部权重，不重新训练 |

## 3. 实施步骤与产物

1. **硬件和工程边界核对**：确认 AX7020、XA7Z020/CLG400 和 `-1` 工作基线；保留硬件验收记录和现有 RTL 工程，不在本阶段综合。
2. **数据与环境准备**：完成官方 HaGRID manifest、五类标签、Darknet 输入绑定和环境检查；最终数据与环境结论已汇总进本记录，不保留大批扫描日志和预览图。
3. **浮点模型准备**：保留 tiny320、tiny416、full608 的外部 cfg/data/weights 绑定；不把失败训练、重复 checkpoint 或诊断权重当成最终模型。
4. **D2 数值规格**：冻结 RGB、Darknet letterbox、CHW/255、对称 INT8、INT32 累加、INT64 溢出审计、BN 折叠和 PS 浮点检测头后处理；保留最新数值证据。
5. **D6 指标规则与 test**：冻结坐标裁剪、IoU/AP 口径和 90% 门槛，完成 tiny416 官方 test；不把网页人工样本或 val 候选替代正式 test。
6. **D3 PC 性能**：固定 20 张 test 图片循环，完成三模型各 100+1000 次模型本体测量；排除进程装载、浏览器传输、预处理、PS 解码/NMS 和显示时间。
7. **D9 与网页**：保留 CPU 解码参考和本地网页；网页调用三套真实只读模型，支持摄像头、单帧导入、三模型对比和人工 Correct/Wrong 统计。
8. **阶段冻结与清理**：以本记录、`STATE.md`、冻结规则、最终证据和代码作为唯一入口；删除失败/重试/预检/候选捕获/重复/review/临时输出。
