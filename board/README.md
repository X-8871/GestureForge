## 当前阶段2B目标器件

2026-10-11，Wong再次明确指定项目芯片为`XC7Z020-2CLG400I`，并授权模型部署和完整2B验收。用户给定订购型号原样保留；Vivado2026.1的唯一对应器件条目仍为`xc7z020clg400-2`，真实查询的DEVICE/PACKAGE/SPEED分别为`xc7z020`/`clg400`/`-2`，没有独立的带`I`条目。查询原件见`report/evidence/S2B-T13/target_query_20261011_r01/query.json`。历史照片差异仍作来源事实保留，器件目录及JTAG不证明实物速度或温度等级；当前部署目标按用户最新指定执行，板级DDR/UART/时钟配置另行核验。

Wong 于 2026-10-08 最后确认「厂商已明确确认实板是XC7Z020-2」，并授权速度等级 `-2`。离线候选使用 Vivado 精确器件名 `xc7z020clg400-2`；厂商资料入口仍为 `D:\FPGA\AX7Z020\AX7Z020`。此前 `xa7z020clg400-1I` 确认已被这次候选目标决定替代。

Vivado 2026.1 精确查询返回唯一同名器件，属性为 `FAMILY=zynq`、`DEVICE=xc7z020`、`PACKAGE=clg400`、`SPEED=-2`。当前工作树 XPR 的项目、综合和实现三个器件字段均为该型号，与 `3375cb4` 基线一致；没有移植原目录的 DCP 或仿真修改。用户新提供的《ALINX黑金AX7020开发板用户手册V2.2》PDF第10、12页明确写有 `XC7Z020-2CLG400I`，其中 `-2` 即速度等级；手册的 `I` 后缀另作资料事实记录。

用户实物照片可直接辨认 `XA7Z020` 与 `CLG400`，与上述厂商确认和新手册的 XC 系列存在冲突。该冲突保留为实物部署前的核实项，不能用 Vivado 器件目录、通用手册或 JTAG 的 `xc7z020_1` 名称证明实物为 XC/-2。可以继续准备此 XC/-2 离线候选，但当前不能据此宣称实物身份或阶段2B G0/G3通过。

最新决定、手册页图、真实查询与历史候选快照见 [目标器件证据](../report/evidence/S2B-T03/target_resolution_20261008_r02/target_confirmation.md)。r01 是已被替代的 XA/-1I 候选证据，保持原始记录；历史阶段0及资料审计保留当时事实。DDR、UART和时钟继续按厂商目录中的对应原理图及例程逐字段核对；本文不代表 PS 平台、整网或时序通过。
