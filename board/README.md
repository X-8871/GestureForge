## 当前硬件基本事实（2026-10-14）

Wong明确确认：「AX7020 器件为 XC7Z020-2CLG400I，Vivado part 应核实为 xc7z020clg400-2；之前的照片的板子的型号也是这个。」该确认针对此前照片中的同一块实板，作为当前工程与部署的器件基线。

| 项目 | 当前值 |
|---|---|
| 开发板 | AX7020 |
| 实物器件型号 | `XC7Z020-2CLG400I` |
| 封装 / 速度等级 / 温度等级 | CLG400 / -2 / I |
| Vivado part | `xc7z020clg400-2` |
| 厂商资料入口 | `D:\FPGA\AX7Z020\AX7Z020` |

本轮Vivado 2026.1实际查询返回唯一匹配，`DEVICE=xc7z020`、`PACKAGE=clg400`、`SPEED=-2`，当前visibility=1平台会话的项目part也为 `xc7z020clg400-2`。主工程 `vivado/AX7Z020_Gesture/AX7Z020_Gesture.xpr` 的项目、综合和实现三个器件字段均匹配。工具使用的part不另带订购型号中的温度后缀 `I`。

此前对照片的XA丝印解读及XA/-1候选属于已被本次确认替代的历史记录，不再作为当前身份冲突或部署阻断项。仅针对XA/-1的补充分析不适用于当前确认的器件，不改变XC/-2平台的时序结论。历史原始查询、手册页图与候选快照见 [目标器件证据](../report/evidence/S2B-T03/target_resolution_20261008_r02/target_confirmation.md)。

DDR、UART、时钟、引脚和电平仍按对应PCB版本的厂商资料核对；器件基线确认与模型实板验收分别记录。
