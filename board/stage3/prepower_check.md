# 首次实物验证关口：断电接口核对

状态：只允许断电检查；不是烧录、上电、接线或最终引脚授权。

## 为什么先停在这里

板卡正反面照片已经取得，板卡身份沿用 AX7020 / `AX701020.3.0`，不要求重发板卡照片。Wong 提供的模块照片中，标签可读为 `ALINX`、`AN5642`、`S/N: 001165`；因此型号/标签序列号已核实，不再重复询问。照片未可靠显示模块版本、Pin1 标记或与板卡的实际插接方向；可见两排连接器焊点，但不能据此猜测 Pin1 或认定已与 J10/J11 兼容。候选板卡图纸也尚未绑定为该 PCB 的最终电气依据。离线生成、语法检查和无最终板卡约束的综合都不能补足这些事实。

因此在接摄像头前先完成下列实物核对。不下载任何临时实验 bitstream；不要使用旧 AX7Z020 图纸上的 J28/J29 调压方法。

## Wong 本次操作

1. 板卡关电，拔掉 5 V 电源和可能供电的 USB；摄像头不接板卡。不要在带电状态插拔排线。
2. 只需核对模块是否另有版本丝印，以及 Pin1 的明确标记；型号 `ALINX AN5642`、标签序列号 `001165` 已由照片确认，不必重复提供。无需再提供板卡照片。
3. 确认实际计划使用模块自带的两排连接器直接插接，还是另有配套排线/转接板；若有排线，说明是否厂商随附及两端标记。此时不要试插到 J10/J11，不按排针外观猜 Pin1。
4. 回传信息后保持断电、摄像头未接，等待针对已核实方向的接线步骤。

预期：能确定模块版本（若有标注）、厂商 Pin1 标记与连接方式。模块身份已确认；仅有“插得进去”不算电气核对通过。

停止条件：无 Pin1/版本标记、排线方向不明确、针脚弯曲或短路、任何文件/实物标记冲突。不要强插、短接、调压或用试上电判断方向。无需进行带电测量；若后续确需测量，先给出经图纸核实的测点和方法，单独确认后执行。

## 下一关不是本次授权

核对完模块与电气资料后才能冻结接线和最终 XDC，再进行相应综合、完整时序、BSP/应用编译及独立审查。届时才提供准确的 bit/ELF 路径、哈希、UART 参数、下载步骤和预期输出。

实际验证顺序为 UART/DDR 基础检查 → HDMI 测试图案 → 单通道传感器 ID/色条/帧行像素计数 → 原始画面及恢复检查 → 已冻结语义的双通道 → 至少 30 分钟耐久。软件故障注入和 PL 离线检查不代表这些实物项目通过；也不取消双目目标或降低原验收标准。
