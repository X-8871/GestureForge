# R-07：真实相机（AN5642 / OV5640）接入显示链路 — 集成方案 · 2026-10-31

- 编制：DSH 项目总控；对应遗留 **R-07**
- 现状：显示链 P3q 的 raw 帧来源是 **DDR 注入**（`0x12000000`，640×480 BGR888，stride 1920，921,600 B）；相机通路在**阶段3 的 `dbdf` 设计**里独立验证过（AN5642/CMOS2 J11），但**未与 P3q 集成**
- 结论：需要**新集成位流 P3r = P3q + AN5642 采集→DDR**；软件侧需按相机格式重映射帧来源（或把显示侧改成"相机直写帧存"）。**约 1 天工作量 + 2 个板窗**

## 2. 方案对比

| 方案 | 做法 | 优点 | 缺点 | 选用 |
|---|---|---|---|---|
| **A. 相机 → DDR raw → 显示软件渲染**（推荐） | P3r = P3q + AN5642 DVP→AXI-Stream→**VDMA(S2MM)**→DDR `0x12000000`（640×480 BGR、stride 1920）；显示软件继续读 raw | 显示链与软件**零改动**（只换帧来源）；复用阶段3 sensor 配置代码 | 多一个 VDMA + 一条 HP 通路；需要传感器切 640×480 | ✅ |
| B. 相机直写显示帧存（相机→FB） | 相机流直接进显示帧存/VDMA | 少一层 | 需缩放/格式转换 + 破坏显示软件假设 + 与 VDMA 读竞争 | ✗ |
| C. 保持 1280×720 相机 + 显示侧缩放 | 相机 720p → 软件缩放到 960×720 视频区 | 画质高 | 软件缩放耗时（CPU 紧张）+ 带宽翻倍 | 备选 |

## 3. 方案 A 的实现分解

| 步骤 | 内容 | 负责 | 工作量 |
|---|---|---|---|
| R07-1 | **BD 设计**：在 P3q 上加 `AN5642 DVP 采集 IP（复用 `dbdf` 的 `alinx_ov5640` + `ov5640_ip`）→ AXI4-Stream → VDMA(S2MM, 非 SG) → DDR 0x12000000`；数据面挂 **HP2（与显示 MM2S 共享）或新增 HP0/HP1 复用**，带宽评估：640×480×3×30 ≈ 27.6 MB/s | `video-bd` | 3–4 h |
| R07-2 | **约束**：J11 引脚（`an5642_j11_cmos2.xdc` 复用）、PCLK 84/48 MHz 时钟、跨时钟 CDC；相机侧 **I/O delay**（见 `R-02-3` 草案 §2.2，需按手册 tSU/tH 填） | `video-bd` | 1 h |
| R07-3 | **传感器配置软件**：复用阶段3 的 `an5642_j11cmos2` 初始化序列，改为 **640×480** 输出（OV5640 寄存器 0x3035/0x3036/0x3808-0x380B 等），并把 VDMA 写几何设为 640×480、stride 1920 | `video-sw` | 2–3 h |
| R07-4 | **集成位流 P3r 构建 + 时序/DRC** | `video-bd` | 1 h（含 2 次迭代余量） |
| R07-5 | **板窗 A**：P3r + 显示软件 + 相机；判据：`0x12000000` 帧头/尾可用、显示出现实时画面、`fps_dis=60` 不掉、`vdma_err=0`；拍照存档 | `board-runner` + Wong 目视 | 1 个窗口（约 20 min） |
| R07-6 | **板窗 B**：长稳 10 min + 相机拔插恢复 + 冷启动复验（与 R-04 合并） | `board-runner` | 1 个窗口（约 30 min） |

## 4. 风险与前置

1. **冷启动问题（R-04）未关闭前**，相机窗口可能受同一初始化时序影响 ⇒ 建议 **R-04 先关，再做 R-07**；
2. **VDMA 带宽竞争**：相机写 27.6 MB/s 与显示读 221 MB/s 共用 HP2/DDR；需在 P3r 上复测欠载（预期影响小，但要测）；
3. **传感器模式切换**（1280×720→640×480）需重新验证 SOF/HREF 补丁是否仍适用（阶段3 的 `GAP_THRESH` 依赖 HTS/VTS）；
4. **不改**阶段3 冻结位流/证据，只**引用**其 sensor 配置与 IP；
5. 相机三脚架/光照等物理条件需 Wong 在场（阶段3 先例）。

## 5. 排期建议

- 前置：R-04 关闭（冷启动 VDMA 显示流）
- 然后：R07-1→R07-4 离线（约 1 天），R07-5/R07-6 两个板窗（约 1 h）
- 可与 R-05（真实推理写端，Codex）并行：两者都只改"数据来源"，不改显示链
