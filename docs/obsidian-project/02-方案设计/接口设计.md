# 接口设计

依据 [[总控#当前用户决策（2026-09-10）]]，主输入为摄像头实时视频；HDMI 路线为偏好，尚未完成硬件核实。

## 接口核对表

| 接口 | 当前选择/倾向 | 必须确认后才冻结 |
|---|---|---|
| 摄像头到板卡 | 倾向 HDMI 摄像头接 HDMI 输入 | 摄像头型号与 HDMI 输出能力；板卡/PCB版本、端口数量及方向、接收器件、视频格式/时钟、电气条件、原理图页码 |
| 板卡到显示器 | 倾向 HDMI 输出 | 发送器件、端口方向、显示器支持格式、约束和时钟来源 |
| PL 处理 | 预处理、卷积、池化及 INT8主要计算已确定 | 像素格式、缩放/灰度规则、帧号、缓存、握手、复位和数值格式 |
| PS 到 PL | 调度及参数配置已确定 | AXI-Lite/Stream/BRAM 等具体接口、寄存器和传输方式未定 |
| PL 到 PS | 读取识别结果 | 类别编码、整数分数/置信度定义、位宽、有效标志、任务号 |
| 交互控制 | PS 控制，形式未定 | HDMI结果显示、LED、UART、切图/显示模式的最终组合 |

## 冻结条件

先核对实物、手册、原理图和端口标识，再定义时钟、复位、引脚与 IOSTANDARD。不得因为有两个外形相同的接口就认定一进一出。无法支持 HDMI 目标链路时记录差距并提交方案选择，不自行切换成网络图片主线。

S0-T01 负责启动核查；具体接线、驱动、XDC 与上板测试另由任务卡约定。图像数据通路与 PS 显示控制分别设计。
