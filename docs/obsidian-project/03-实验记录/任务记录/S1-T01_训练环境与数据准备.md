## Wong数据采集与标注操作单（S1-T01）

### 目的与前提

- 本操作单只用于补齐 S1-T01 的真实图片、标签和分组输入，不涉及板卡、烧录或正式长训。
- 大型 HaGRIDv2 数据和个人原图放在 Git 仓库外的独立目录；仓库只保存数据说明、清单、来源、许可和校验值，不上传个人原图或整库压缩包。

### 采集步骤

1. 使用预计接入项目的摄像头或同等视角设备，采集 `fist`、`palm`、`one`、`two_up`、`three` 五类，以及无手/非目标手势负样本。
2. 至少准备 3 个拍摄会话，每个会话都覆盖五类；改变距离、背景和光照，避免只截取同一段视频的相邻帧。
3. S1-T01 最低流程门槛为至少 30 张真实图片、每类至少 5 个框、至少 5 张无手图；为确保训练/验证两组都覆盖五类和无手，建议每类每会话至少 6 张，并额外准备 10 张无手/非目标图。
4. 按会话保存，例如 `session_01/images/`、`session_02/images/`、`session_03/images/`，保留原始文件名、采集日期、设备和拍摄条件。

### 标注规则

1. 类别编码固定为 `0=fist`、`1=palm`、`2=one`、`3=two_up`、`4=three`。
2. 每只目标手单独标注紧外接框，导出归一化 YOLO 格式：`class_id center_x center_y width height`；坐标范围为 `[0,1]`。
3. 单手图片只标注该手；多手图片逐手标注所有可识别的目标手。暂不把无法归入五类的手势标为五类。
4. 无手图保留同名空标签文件；非目标手势作为负样本单独记录，不能伪标成五类。
5. 遮挡或截断但仍可明确辨认的手保留并记录属性；无法可靠辨认的样本移入待复核目录，不直接用于验收。

### 划分与回传

1. 按拍摄会话划分，不按图片随机切分：会话1用于训练流程，会话2用于验证，会话3保留为独立测试候选；相邻帧不得跨集合。
2. 回传完整数据根目录、每个会话的图片数量、五类框数、无手/非目标数量、设备与拍摄条件、来源许可说明和目录压缩包 SHA-256。
3. 若暂时只有 HaGRIDv2，则先回传选定子集的来源版本、目标类别、`user_id` 划分和转换结果；不要下载完整数据集，也不要将 HAGRID 指标代替 Wong 数据测试结果。

### 异常停止条件

- 发现个人图片将被上传到不明第三方服务、来源许可无法确认、标签无法判断、文件损坏或会话信息缺失时停止整理并回报，不自行猜测或混入训练集。
