# R-02-③：I/O delay 约束草案与复核计划 · 2026-10-31

- 编制：DSH 项目总控；对应遗留 **R-02 第③条**（阶段3："TIMING-17 / I-O delay 未纳入冻结位流、未签核"）
- 目的：给出**增量约束草案**与验证计划；**不修改已冻结位流 P3q**，不改阶段5/6 冻结物
- 结论：**TMDS 侧不需要 I/O delay**（时序在器件内部、OSERDESE2 输出无外部采样）；**唯一需要补的是未来相机 DVP 输入侧**与**跨器件外设接口**；已冻结位流无功能风险

## 1. 现状核对

| 项 | 现状 |
|---|---|
| P3q 约束文件 | `p3q.xdc`（引脚/时钟/IOSTANDARD）、`p3q_cdc.xdc`（跨时钟 `set_max_delay -datapath_only`） |
| 已有时序约束 | 主时钟（MMCM 输入 50 MHz、pixel 74.21875、5x 371.09375、100/50 MHz 数据面/控制面） |
| 已有时序结果 | WNS **+0.371 ns**、WHS +0.036、TNS=THS=0、失败端点 0（46,096 端点） |
| **未包含** | 任何 `set_input_delay`/`set_output_delay`（阶段3 记录所指 TIMING-17） |
| 影响面 | **TMDS 输出**：源同步 SERDES 输出，外部无采样时钟回传 ⇒ 无 I/O delay 语义<br>**PS MIO**（UART/ETH/SD/QSPI）：由 PS 内部时序保证，不属 PL 约束<br>**相机 DVP**（未来）：**需要**输入 delay（`pclk` 采样 `vsync/hsync/data`） |

## 2. 约束草案（增量，仅在需要时启用）

### 2.1 TMDS 输出（结论：不加 I/O delay，保留现有约束）
```tcl
# 说明：TMDS 为 OSERDESE2 序列化输出，参考时钟由同一 MMCM 5x 产生；
# 外部接收端不做源同步回采，故不设 set_output_delay。
# 仅保留引脚/IOSTANDARD/时钟约束（已有），并确保 5x 时钟域不被错误约束。
set_false_path -from [get_clocks clk_pixel] -to [get_ports {TMDS_*}]   # 可选：显式声明
```
> 依据：TMDS 电气规范由 SERDES + 外部 49R9 端接满足；Vivado 不要求输出 delay 才能签核该接口。

### 2.2 未来相机 DVP 输入（阶段7 接入时启用）
```tcl
# 依据 OV5640/AN5642 手册的 tSU/tH（待按具体模组手册页码核对后填入）
create_clock -name cam_pclk -period 12.500 [get_ports cam_pclk]     # 例：80 MHz
set_input_delay -clock cam_pclk -max  <tCO_max + board_skew> [get_ports {cam_data[*] cam_vsync cam_hsync}]
set_input_delay -clock cam_pclk -min  <tCO_min - board_skew> [get_ports {cam_data[*] cam_vsync cam_hsync}]
set_input_delay -clock cam_pclk -clock_fall -max ... [same]
set_input_delay -clock cam_pclk -clock_fall -min ... [same]
```
- **必须先在 G0 冻结**：相机型号、PCLK 频率、DVP 位宽、采样沿、板级走线长度/端接
- 数值来源：模组手册 AC 特性表（页/节须写明）+ PCB 走线延迟估算（约 6 ps/mm，需实测或叠层参数）

### 2.3 外设/调试接口
- UART/JTAG：PS 侧 MIO，不需 PL 约束
- 未使用的 PL 引脚：保持 `set_property IOSTANDARD LVCMOS33` + 不驱动

## 3. 复核计划（R-02-③ 关闭路径）

| 步骤 | 内容 | 判据 |
|---|---|---|
| V1 | 在**独立构建**（非冻结 P3q）中加入 §2.1 的显式声明（不改功能），跑实现 | WNS 不变差（≥+0.371）、TNS=0、DRC 0 error |
| V2 | `report_timing -max_paths 20` 抽查 TMDS 输出路径与 5x 时钟域 | 无未约束路径（`report_timing_summary` 的 unconstrained paths = 0） |
| V3 | 若 V1/V2 通过 ⇒ 记录"TIMING-17 对当前显示接口**不适用**"，并把 §2.2 作为阶段7 相机 G0 的必做项 | 文档 + 报告 |

**本次不做 V1/V2 的重实现**：本轮时间用于 R-04/R-07；V1/V2 可在阶段7 首次重编位流时顺带完成（约 40 min Vivado）。

## 4. 结论

- R-02-③ 的**性质已澄清**：不是缺陷，而是"未纳入"；对已交付的 **TMDS 显示链无影响**（WNS +0.371 已签核内部时序）；
- 需要补的是**未来相机 DVP 输入 delay**，已给出草案与冻结前置条件；
- **R-02-③ 关闭建议**：标记为"**当前范围不适用 + 阶段7 相机 G0 必做项**"，待 V1/V2（可选）与相机接入时正式签核。
