# S1-T02-D3 资源、性能与阶段验收门槛

状态：`REFERENCE_SPEC_READY_REVIEW_REQUIRED`。本记录只把 Wong 已批准的资源、性能统计和 G0—G4 判定口径编码为可检查规范；没有宣称 Vivado 综合、真实板上性能、最终 FPS、最终延迟或阶段验收通过。

## 1. 范围和模型角色

| 模型 | 角色 | 资源适用性 | 性能/PC预算 |
|---|---|---|---|
| YOLOv4-tiny 320 | `board_candidate` | 适用，单独统计 | 适用 |
| YOLOv4-tiny 416 | `board_candidate` | 适用，单独统计 | 适用 |
| 完整 YOLOv4 | `pc_only_reference` | 不适用板上资源验收 | 仅保留 PC 计算/存储预算 |

固定硬件基线为 AX7Z020 / XA7Z020 / CLG400，时序速度等级按 `-1` 工作基线。三组模型必须分别绑定 cfg、权重版本、输入尺寸、预处理版本和数据/评估口径；缺少正式五类权重时只能记录 `PENDING`，不能用诊断权重替代最终模型。

## 2. 资源 schema 和判定

机器 JSON `s1_t02_d3_resource_performance_v1` 顶层包含 `hardware_baseline`、`thresholds`、`models`、`file_bindings` 和 `provenance_requests`。每个模型的 `resource` 必须包含：

- `evidence.estimate`、`evidence.synthesis`、`evidence.board_measurement` 三个独立对象，`evidence_kind` 分别只能是 `estimate`、`synthesis`、`board_measurement`；
- `utilization`：`lut_pct`、`ff_pct`、`bram_pct`、`dsp_pct`，每项位于 `[0,100]` 且不超过 85%；
- `timing`：WNS/WHS 不小于 0，TNS/THS 必须为 0；
- `storage`：`weights_bytes`、`feature_map_peak_bytes`、`frame_buffer_bytes`、`ps_buffer_bytes`、`ddr_peak_bytes` 分栏，另列半开地址区间并检查无重叠；
- `ddr_bandwidth`：视频输入、模型传输、PS 解码/NMS、缓存竞争和 `total_peak_bytes_per_s` 分项，合计必须覆盖各组成项。

`estimate` 只能表示公式、parser 或预算结果；`synthesis` 必须来自目标工程综合/实现；`board_measurement` 必须来自目标板真实测量。缺少后两者时检查器返回 `NOT_EXECUTED_PENDING`，不会把估算升级为 `PASS`。完整 YOLOv4 的板上资源项为 `NOT_APPLICABLE`，不因此产生资源通过结论。

## 3. 性能 schema 和判定

每个模型的 `performance.fixed_config` 必须绑定模型标识、输入尺寸、权重 SHA、cfg SHA、预处理 SHA、score threshold、NMS IoU 和最大输出框数。正式测量固定为 100 次 warmup、至少 10000 次有效推理，全部样本参与，不筛选快样本。

`stages` 必须同时包含 `preprocess`、`pl_model`、`ps_decode_nms`、`display` 和 `end_to_end`，每阶段记录 mean、P50、P95、P99；`failure_counts` 单列 timeout、drop、failure。有效推理不足 10000 时，已标为测量的证据失败；未开始测量则是 `NOT_EXECUTED_PENDING`。

旧分类方案的 20 FPS、100 ms、3—5 倍加速不属于当前门槛。`final_threshold_status` 固定为 `pending_until_wong_decision`，最终 FPS、端到端 P99 和 ARM 对照目标待资源/性能证据形成后由 Wong 决策。

## 4. 关口状态语义

每项只允许以下语义：

- `MEASURED`：有对应原始测量和版本绑定；
- `NOT_EXECUTED`：本轮明确未执行；
- `NOT_APPLICABLE`：技术上不适用，并写明理由；
- `PENDING`：依赖尚未冻结或证据尚未齐全。

检查器的 `schema_valid=true` 只表示结构、范围和异常语义合法，不代表验收通过。存在缺失实测时总状态为 `NOT_EXECUTED_PENDING`；证据齐全但最终门槛仍待 Wong 决策时为 `READY_FOR_WONG_DECISION`。只有适用关口的真实证据完成后，才可由总控判定对应 G1/G2/G3/G4，不能把工具自测当综合或板上证据。

G0 需要冻结任务输入、口径和阈值；G1 检查器与证据结构可复现；G2 由独立 Reviewer 核对来源、版本和边界；G3 只适用于 tiny 的目标板资源/性能实测，full 为 PC-only；G4 要求精度、数值、资源和性能适用证据同时满足并由 Wong 确认。
