## 资料核对范围

- 手册、原理图和硬件资料中的 DDR、视频接口、UART、JTAG 和供电信息作为后续工程依据。
- `CLG400` 只表示封装，不等于速度等级；芯片表面 `ABX2117` 不作为 `-2` 证明。
- JTAG 显示 `xc7z020_1` 只证明 Zynq-7020 类器件，不据此改写实物的 `XA7Z020` 标记。
- HDMI 的输入/输出端口方向和摄像头兼容性仍需阶段 3 用实际视频链路验证，不能由接口外观推断。

## 阶段0边界

本阶段通过不代表以下功能已经通过：

- UART 实际输出和 PS 启动；
- DDR 读写和缓存一致性；
- HDMI 摄像头输入、视频直通和显示；
- YOLO 模型训练、量化、推理和性能。

UART 功能测试进入阶段 2；DDR 运行验证按固定输入上板任务执行；HDMI 原始画面验证进入阶段 3。
