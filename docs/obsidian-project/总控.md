## 2. 项目稳定事实

| 项目 | 当前信息 |
|---|---|
| 项目名称 | 基于 AX7Z020 的低比特神经网络 FPGA 加速系统，实现摄像头手势识别并驱动板卡进行实时交互 |
| 参赛方向 | FPGA 创新设计赛道中的自主选题赛道；组别待报名确认 |
| 目标平台 | ALINX AX7020；板载 FPGA 实物为 XA7Z020、CLG400，工程按 XA 目标和 `-1` 速度基线维护 |
| 核心任务 | 摄像头采集手势 → FPGA/PL 预处理与 INT8 推理 → PS 解析 → HDMI/LED 实时交互 |
| 检测类别 | 握拳、手掌、数字一、数字二、数字三，共 5 类静态手势 |
| 当前队伍 | 用户与指导老师；其他队员以用户后续确认为准 |
| 作品目标 | 提交前达到国三与国二之间；初审通过后强化到国二与国一之间 |
| 论文安排 | 考研结束后再考虑，当前不占用作品开发主线 |
| 当前阶段 | 阶段0已通过；阶段1 PC模型与数值规格文档已收尾，模型实施状态见 [[项目进程#1. 当前状态\|唯一当前状态]] |
| 报名状态 | 尚未报名；需要准备选题方向和作品简介 |

### 竞赛提交要求摘要

- 必须提交完整工程、源码、仿真/验证结果、综合与实现报告、上板工程、运行脚本和实测输出。
- 工程目录和文件名使用英文、数字、下划线或连字符；中文只用于文档正文。
- 需要保存大模型协作记录，并将可复用经验整理为 `skill/` 技能包。
- 评分核心为创新与应用、性能与资源、功能完整性、AI 协作与 Skill、文档与复现；具体权重见 [[01-竞赛材料/赛道规则|赛道规则]]。

## 3. 当前系统边界

### 必须完成

- AX7Z020 工程能够建立、编译和上板运行。
- 完成一个可解释的低比特神经网络推理链路。
- 最终实现摄像头实时视频输入、PL 推理、识别结果与板卡交互闭环；固定图像仅作调试和阶段性验证。
- 提供精度、延迟、资源占用和运行稳定性的基本证据。
- 形成报名简介、作品说明、演示视频和答辩材料。

### 暂不扩张

- 只部署一套候选PL网络；允许完整YOLOv4与tiny作PC精度对照，不扩展其他应用场景。
- 不在基础版本阶段追求复杂摄像头算法、复杂 UI 或大模型。
- 不在作品提交前强行写论文。
- 不在没有测量数据前宣称“实时”“低功耗”或“显著加速”。

- 阶段0已按板卡身份、器件系列、封装、JTAG、资料对应和 XA 目标工程验证范围通过。
- 芯片实物标记为 `XA7Z020 CLG400`，JTAG IDCODE 为 `0x23727093`；Vivado 显示 `xc7z020_1` 只作为 Zynq-7020 类识别，不作为 XC 系列或 `-2` 速度等级证明。
- UART 线已连接，功能输出测试留在阶段2；精确速度等级待供应商或原厂材料确认，后续按 `-1` 速度基线进行时序设计。
- 阶段1已完成文档、接口、数据集、量化和验收口径收尾，尚无 YOLO 训练、INT8 检测量化或完整黄金结果。入口为 [[04-提交材料/阶段验收/阶段1_PC模型与数值规格收尾记录]]。

## 当前用户决策（2026-09-11）

- 已确定：摄像头实时视频，检测握拳、手掌、数字一、数字二、数字三，输出检测框、类别和分数，并形成板卡交互。
- 已批准推进：YOLOv4-tiny优先上板候选，完整YOLOv4作为PC精度对照。先比较320/416彩色输入，完成精度、数值和资源三关，再由Wong确认冻结模型与性能。
- PL负责预处理与INT8主要计算；PS负责调度、配置、检测头解码、阈值筛选/NMS、显示与交互控制；DDR/BRAM分块设计见 [[02-方案设计/系统设计]]。
- HDMI摄像头→HDMI输入→FPGA→HDMI输出为偏好；板卡与接口资料已核对，端口方向、接收/发送器件和摄像头兼容性仍需阶段3实测。

- HDMI结果显示与稳定手势切换显示状态按阶段计划推进；附加LED等形式按任务冻结。不因改方案宣称模型或硬件验收通过。

## 当前用户决策（2026-09-13）

- PC 小样本训练采用固定版本的官方 Darknet；YOLOv4-tiny 配置改为五类，具体仓库提交和 cfg 文件哈希在环境准备后登记。完整 YOLOv4 仍只作 PC 对照，不进入 PL 主线。
- 当前五类及暂定编码为：`0=fist`、`1=palm`、`2=one`、`3=two_up`、`4=three`。
- HaGRIDv2 作为优先种子数据源；采用其五个目标类的手部框标注，`no_gesture` 和自采无手/非目标样本作为负样本候选。HaGRIDv2 不直接等同于最终用户场景，最终测试需保留 Wong 摄像头、背景和多会话数据。
- 不下载完整 HaGRIDv2；数据子集、存储位置、来源许可记录和与自采数据的混合比例待 S1-T01 核实。
