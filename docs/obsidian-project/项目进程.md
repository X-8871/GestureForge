## 1.1 板卡验证门槛

板卡不是每个学习步骤都要使用，而是在仿真无法证明的地方使用：

1. **环境门槛**：确认 AX7Z020 实物、芯片型号、供电、JTAG/USB、串口和基本外设。
2. **上板门槛**：下载最小 LED/计数器工程，证明 Vivado 工程、约束、下载链路和时钟复位可用。
3. **系统门槛**：联调 PS/PL、AXI/BRAM/UART 等数据链路，记录真实输出和异常现象。
4. **作品门槛**：验证摄像头、预处理、YOLO 检测推理和 HDMI/LED 交互，形成可连续演示的闭环。

计数器、FSM、RAM/ROM、INT8 MAC 的第一轮功能验证优先使用仿真；模型训练、量化和 Python 黄金参考在 PC 上完成。9 月 10 日前不要求完成摄像头或完整 CNN 上板。
