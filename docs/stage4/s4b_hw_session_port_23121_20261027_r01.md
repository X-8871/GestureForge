## 3. 新发现的结构性阻断（本轮核心结论）

冻结 2B 工具 `verification/s2b_board_jtag.py` 的 `JtagController.__init__` 硬性要求：

```python
require(... self.peer.get("Port") == "3121", "必须借用总控连接的localhost:3121会话")
```

⇒ **即使会话建在 23121、门禁 8/8，`execute_prepared → JtagController` 的 peer 校验必拒**。
冻结端到端 PS 张量诊断在本机当前网络状态下不可达。该文件属 2B 冻结交付（delivery_manifest 绑 SHA），阶段4 不得改写。

  （释放排除区间）→ 停掉 23121 的 hw_server → 以默认端口重启 hw_server（3121）→ 重新取证
