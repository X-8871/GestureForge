## 4. 不得做的事（防误报）

- 不得把**合成源**既有结论（四 FPS、120 帧五元组、31.06 min）当作真实集成通过，也不重跑改写其 RunId。
- 不得把 P1 现行「宿主预计算框」当作板上动态映射；只有板上执行映射并逐像素对拍后才可关闭 §4.5 缺口。
- 不得用 `0x503D`（传感器内部彩条寄存器）充当无摄像头时的图源；它是**数传通路测试源**，非常规重置工具，
  用前存原值、读回、恢复 `0x00`。
- 不得把 J10 半屏黑写成「已修复/已关闭」：Wong 2026-10-24 已将其移出范围（当前 J11/CMOS2）。
- 不得因「无 ILA」免掉功能/时序/耐久标准，也不得在本轮改许可或植入调试核。
- 不得把 `capture_fps`、端到端延迟等未实测项填 0 或推测值。
- **不得**把重复/乱序/回退结果当"最新结果"叠加或幂等静默接受：按阶段4 r04 `frame_sequence_rules`
  必须**拒绝并记 FAIL**，且拒绝要落日志、记原因（不只记计数）；板上实现必须与离线骨架同构。
- 不得把合成流的长跑（离线虚拟 30 分钟）当作板上 ≥30 分钟耐久证据。
