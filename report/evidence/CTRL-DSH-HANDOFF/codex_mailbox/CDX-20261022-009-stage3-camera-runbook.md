## 2. 到货前：现在执行

### 3-A 采购兼容性核验

负责人整理一页采购检查表，Wong确认采购：
1. 完整商品型号、PCB版本、传感器型号、供应商实物照片。AN5642模块使用OV5640，不根据“5642”推断传感器。
2. 按实际板卡PCB/BOM和厂商资料逐针核对供电、电平、地、DVP数据位、PCLK、VSYNC、HREF、SCCB、RESET/PWDN。记录资料页码及版本。
3. 核对接头方向、通道、排针/排线机械适配；不能因同为DVP就直接连接。
4. 核对目标1280×720、RGB565及初始化支持；获取原厂例程与模块测试/售后条件。
5. 同型号同版本优先评估复用；若改USB/HDMI/MIPI，暂停依赖旧采集链的实现决定，先让Wong批准接口变更范围。
6. 输出兼容性表、预算/交期/版本依据；未知项逐项列出，不把销售口头“兼容”当电气核验。

### 3-B 保全恢复依赖并关闭可离线处理的遗留项

1. 按现有manifest逐项验证冻结bit/XSA/ELF实际存在与SHA。缓存已经清理过，旧路径存在性不能靠历史manifest推断；缺失时先定位已验证归档或重建方案，不直接启动旧命令。
2. 记录标准亮度灰度bit：
   `44e609ccc62647c1748cbeecc64b2fdaa0c53b07db6b7bd1c8a230ca65fc4afb`；
   XSA：`90e1bdee1f5baaf9e772edcddc800aab6927d2099b54a45bc020025d82ccb1c4`。
3. 只读复查stdluma补丁与网表映射，补完整独立审查；构建如有需要，使用新RunId且先检查重资源占用。
4. 列清VDMA `0x00015810`、TIMING-17/36、I/O delay、J10半屏等未关闭项。对正式使用路径有影响的项要修复/验证；不用J10不等于J10缺陷已修，只能注明不在部署范围。
5. 不把历史manifest中的机器核验当PASS：本次读取其 `machine_check.exit_code=2`。需要新证据时按总入口给出的正确检查器参数和schema生成，不覆盖旧清单。

**输出**：采购兼容性表、恢复产物核验、遗留项处置表、独立审查。摄像头相关状态仍为BLOCKED。

## 3. 到货后：必须满足硬件授权与独占条件

### 3-C 安装与首次上电

1. Wong/授权实物操作者断电更换模块，记录新旧模块身份、接头方向与照片；禁止热插拔默认试错。
2. 阶段总控核对本次硬件占用，绑定目标JTAG身份、板卡、器件及当前会话。旧PID不能复用。
3. 使用经完整哈希核对的无补偿SOF修复基线与匹配软件；旧基线bit为
   `7cb330685260ced38636d3e90a92160979b0f88770d380269e9864722ce48710`。
   必须重新核对XSA/BSP/ELF兼容性；禁止以补偿/灰度位流验证真彩。
4. 先读取传感器ID与初始化结果，再开始数据路径。错误ID、无ACK、配置不符即停止，不靠继续写随机寄存器尝试。
5. 保存UART原文、bit/XSA/ELF哈希、读回配置、帧地址和stride。每次硬件尝试独立RunId。

### 3-D 缺位与颜色验证

1. 启用传感器内部已知彩条，核对正常输出模式和RGB565顺序；`0x503D`属于传感器，摄像头缺位时不能用它造图。
2. 用经审查的cache一致性取帧/停写/转储流程抓完整帧及代表行；先从当前ELF/UART核对地址、stride、长度，不能硬编码旧地址。
3. 对正确像素布局的非空样本检查蓝bit7、绿bit4、彩条期望值与顺序。各条带排除边缘过渡区域。
4. 用白/黑/彩色物体与运动场景核对颜色、曝光、稳定性；照片仅补充，数值帧必须保存。
5. 恢复普通传感器输出并读回确认，保存恢复后帧；不得把彩条模式留作“真实画面”演示。

已有离线辅助命令（当前阶段树执行，ROW_FILES须是核对过的具体文件数组）：

~~~bash
"$PYTHON" -B scripts/stage3_t05/analyze_missing_msb_signature.py "${ROW_FILES[@]}"
~~~

**特别注意退出码**：该脚本0表示“符合旧缺位签名”，1表示“不符合该签名”，2表示用法/缺输入；不符合旧签名并不独立证明修好。先保证文件非空、长度为3的倍数、B/G/R字节顺序一致。脚本会跳过部分无效长度输入，所以必须另核对实际扫描数量，不能把跳过当通过。

### 3-E 帧同步、错误计数和耐久

1. 对1280×720配置验证每行有效像素数、每帧有效行数、帧开始/结束事件；记录预期与实测。
2. 区分采集帧、缓存写完帧、显示帧；对运动源检查撕裂、停帧、花屏和丢帧策略。
3. 保存VDMA错误寄存器启动值、运行增量和结束值，不能清零后隐藏历史失败；解释并关闭正式路径异常。
4. 按冻结配置连续≥30分钟，不人工复位；保存计数、错误、帧时间日志及连续视频。出现死锁/数据破坏时停止本次验收，保全日志，修复后新RunId完整重测。
5. 完成当前部署实现的时序/约束审查；DRC零错误或WNS为正不能替代缺失I/O约束核验。
