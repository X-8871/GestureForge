## 2. 窗口第 0 步（每次开窗必做，逐项留证）

1. **占用核查**：无 `hw_server`/`xsdb`/Vivado/Vitis/xsim 进程、3121 未监听、COM4 未被占用、无 `index.lock`；一次只跑一个重型任务。
2. **部署身份逐字符核对**：按 P3 确认的那一套重算 SHA-256 并与之比对（禁止"文件名相同即视为同一版本"）。
3. **运行期地址回读**：`ADDR_S2MM`/`ADDR_MM2S`（阶段3 已证为运行期分配）——**禁止复用旧地址**。
4. **真彩目视重做**：Wong 在场；记录为**人工观察证据**，写明失效条件（部署/端口/接线变更即失效）。
5. **门禁如实登记**：凡未成立的类别一律写"未成立"，不得自认齐全。

## 4. 允许 / 禁止

- **允许**：易失 JTAG 下载已冻结部署、读寄存器/内存、开串口读日志、摄像头采帧、`hw_server`/`xsdb`（用完即停）。
- **禁止**：烧 QSPI、改接线/电气测量、改冻结件（cfg/权重/校准清单/地址图/契约）、改他人树、结束他方进程、未授权改 `ENABLE`、push、`fsck --lost-found` 之类写入仓库的命令。

## 5. 停止条件（命中即停，保留现场）

1. 身份不一致 / 地址与运行期回读不符；
2. 复位、死锁、无法解释的错配；
3. 出现"要改设计才能继续"的需求；
4. Wong 要求收窗；
5. 单次窗口超过 3 小时。
⇒ 停止时：保留原始日志与产物、记录停止原因与恢复入口，**不删失败证据**。
