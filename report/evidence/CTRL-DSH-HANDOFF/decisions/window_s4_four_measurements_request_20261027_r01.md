| # | 实测项 | 判定口径 |
|---|---|---|

| M2 | **无其他 DDR consumer** | 枚举并记录运行中的 PL/AXI 主设备与 DMA；确认无对该候选区的访问路径；列出证据（寄存器/设计绑定） |
| M3 | **候选区实际未被占用** | 对 `[0x12000000,0x12C08000)`（12,615,680 B）：先**只读快照**前 4 KiB 与末 4 KiB → 写入已知图样（每 4 KiB 边界写入并逐字回读）→ 间隔 ≥10 s 再回读一次确认未被他人改写 → **恢复原字节**并逐字校验恢复成功 |
| M4 | **cache 维护与可见性** | 按 64 B 向外取整做维护；验证写后可见性（CPU 写 → 维护 → 回读；以及 DMA 可见性按设计路径验证或如实登记"无法在本窗口验证"） |
