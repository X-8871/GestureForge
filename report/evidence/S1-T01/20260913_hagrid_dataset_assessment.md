# S1-T01 HaGRIDv2 数据源评估证据

## 评估信息

- 日期：2026-09-13（UTC+8）
- 来源：[hukenovs/hagrid](https://github.com/hukenovs/hagrid)
- 目的：评估其作为五类手势检测种子数据源的适配性，不代表数据已下载、许可审查已完成或模型已训练。

## 与项目需求的对应

| 项目需求 | HaGRIDv2 情况 | 本项目处理 |
|---|---|---|
| 五类手势 | 包含 `fist`、`palm`、`one`、`two_up`、`three` | 作为五个正类，暂定编码 0—4 |
| 检测框 | 提供逐手归一化 COCO 框 `[x, y, width, height]` | 转换为 Darknet YOLO 标签，保留逐手框 |
| 人员隔离 | 提供 `user_id`，官方 train/val/test 按人员划分 | 禁止按相邻视频帧随机切分 |
| 无手/未知输入 | 提供 `no_gesture`，另有其他手势类 | 不设为第六个输出类；作为负样本候选，并补充自采无手/非目标样本 |
| 摄像头泛化 | 有室内、光照和 0.5—4 米距离变化，但不等于 Wong 的实际摄像头条件 | 用 Wong 摄像头多会话数据做微调和独立测试 |

## 存储与许可风险

- 官方仓库说明 HaGRIDv2 约 1.5 TB；`fist`、`one`、`palm`、`two_up`、`three` 五个训练压缩包按页面标注合计约 212 GB。
- 当前工程所在 D 盘可用空间约 306 GB，不下载完整五类原始压缩包；后续采用确定性抽样、外部存储或仅使用经许可的子集。
- 官方仓库说明采用 CC BY-SA 4.0 的变体并提供单独许可证文件。提交或公开发布前必须保存来源、版本、许可文本和使用范围记录；本评估不替代许可审查。

## 决策

- 推荐方案：HaGRIDv2 五类子集作为种子训练/流程验证数据，Wong 摄像头采集数据作为微调和最终独立测试数据。
- 不把 HaGRIDv2 的公开模型指标直接当作本项目指标；不把 HaGRIDv2 的完整数据集复制进 Git。
- 当前未下载、未转换、未训练；S1-T01 仍处于 G0 核验中。
