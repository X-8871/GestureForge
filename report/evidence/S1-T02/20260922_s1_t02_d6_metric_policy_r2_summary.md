# S1-T02-D6 r2：阶段一正式检测门槛冻结

## 本轮决定

2026-09-22，按 Wong 的授权冻结阶段一 PC 检测口径：

- 浮点正式门槛：`mAP@0.5 >= 0.90`、`mAP@0.5:0.95 >= 0.70`，且五类每类 precision、recall 均 `>= 0.90`。
- INT8 对比门槛：相对绑定的浮点版本，`mAP@0.5` 绝对下降不超过 5 个百分点，逐类 recall 绝对下降不超过 5 个百分点；D2 溢出规则仍必须满足。
- `score_threshold=0.25`、NMS IoU `0.45`、每图最多 `15` 框不再由 test 或网页人工样本调参。
- `no_hand` 不再是阶段一阻断项。网页可以观察无手样本，但无手不计入五类准确率；官方 `no_gesture` 不得改写成 `no_hand`。

## 已有正式 test 结果

tiny416 使用官方 HaGRID test 的 25,484 张图，在固定口径下得到：

| 指标 | 结果 | 门槛 |
|---|---:|---:|
| mAP@0.5 | 0.9774176565 | >= 0.90 |
| mAP@0.5:0.95 | 0.7700877728 | >= 0.70 |
| 五类 precision 最小值 | 0.9479207151 | >= 0.90 |
| 五类 recall 最小值 | 0.9701880752 | >= 0.90 |

因此，tiny416 通过本轮冻结的浮点数值门槛。该结果仍需与 D2、D3、本网页证据、独立审查和 Git 冻结一起组成阶段一收尾，不单独宣称阶段 G4/G5。

## 来源审计结论

本机只有官方 [HaGRID 仓库](https://github.com/hukenovs/hagrid) 也足以维持主数据来源。已检查官方 v1 `subsample` 候选和其他 GitHub no-hand 候选；没有找到同时满足当前正式 person/session 审计、全帧语义和可复现绑定的独立 `no_hand` 来源。因此本轮按授权继续，不下载大包、不重新训练、不把不合适的负样本塞入正式 test。

机器详情见同目录 `20260922_s1_t02_d6_metric_policy_r2.json`；r1 保留为历史授权快照，不删除、不覆盖。
