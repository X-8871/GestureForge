# S3-T05 偏色定位（按字节测量，2026-10-20 13:2x–13:3x UTC+8）

## 1. 方法（只读、可复核）

1. 上板运行彩条版 v6 ELF（`0x503D=0x80`，回读确认）；
2. 用 JTAG `mrd -bin -file` 把 **y=360 整行 3840 字节**（帧缓冲 `0x00110C00 + 360*3840`）二进制转储到 `row360.bin`；
3. 主机侧按 **3 字节/像素**切片（1280 像素）并检测分段 → 得到 8 个实心条 + 条间 1–2 像素过渡；
4. 脚本：`scripts/stage3_t05/jtag_dump_row.tcl`；原始转储 `row360.bin`；分段结果 `row360_segments.txt`。

## 3. 结论

- **条的宽度≈160 像素 × 8 条**，与“8 条标准彩条”一致；**色相与顺序都对**（白/黄/青/绿/品红/红/蓝/黑），
  ⇒ **不存在通道错位或字节序错位**（否则黄/青、红/蓝会互换，Wong 的照片与此不符）。
- **蓝色分量被系统性压低到约 42%**：白条 B=120（应 248）、青条 B=96（应 248）、品红 B=120（应 248）、蓝条 B=96（应 248）；
  而不含蓝的条（黄/绿/红）B 仅为 0–32 ≈ 0 ✓。绿分量 236（应 252，−6%）、红分量 224–248（≈满）基本正常。
- ⇒ **偏黄 = 采集侧蓝通道增益偏低**，**不是显示器**（Wong 已确认显示器菜单/其他内容正常）、也不是色彩通道映射错误。
- 量化：以白条为例，实测 (248,236,120) vs 期望 (248,252,248) → 蓝约为期望的 48%，绿约 94%，红 100%。

## 4. 待验证的候选成因（均未排除）

1. **传感器 ISP/AWB**：厂商 init 表 `0x5001=0xa3`（AWB 开）。若测试图插入点在 AWB/色彩矩阵之前，AWB 的偏暖增益同样会作用于测试图；
   且首张实景照片以黄色墙面为主，AWB 在单色场景下容易向反方向收敛（越调越黄）。**下一步用 A/B 关闭 AWB 复测白条蓝分量**。
2. DVP 数据位/采集 IP 的字节处理（若属实，通常不会表现为“均匀 0.42 增益”，优先级低于 1）。
3. 565→888 扩展本身只会造成 R/B 满量程 248、G 252 的极轻微差异，**量级远不足以解释 42% 的蓝缺失**（已排除）。

## 5. 限制

- 判读基于**一条扫描行**（y=360）与**单一彩条图案**；未做多行/多图案复核；未用色卡或仪器。
- 通道顺序 (R,G,B)=(c3,c2,c1) 由“黄条必须显黄、青条必须显青”反推，与 Wong 的照片一致；若日后发现有出入需重判。
- 未做 AWB 关闭实验（需新 ELF）；未修改任何传感器寄存器（本轮只读取帧缓冲）。
