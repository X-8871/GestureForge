# S3-T05 DVP 输出级受控实验方案（不依赖上板即可准备）— 2026-10-21 21:5x

## 0. 目标

在**不改接线、不测电气**的前提下，用**寄存器读回 + 单变量写测试**区分三种可能：
(A) 传感器把该位输出到寄存器固定值（**软件可修**）；
(B) 传感器正常输出、**模块该走线/焊点断**（硬件，返修/更换）；
(C) 传感器该脚未输出（源端问题，需换传感器/模块）。

**关键**：`cmos_d[9]` 承载两个 DVP 字节的 MSB。若 `0x301D[3]`（D9 对应的 output select 位）为 1，D9 将输出**寄存器固定值**而不是数据 —— 症状正是**该线恒为固定电平（0）**、且与场景无关，与我们实测签名完全一致。

## 2. 已有实测（无需上板）

- 19 个行样本、24,320 像素：蓝 8 位 bit7 置位率 **0.000%**、绿 8 位 bit4 置位率 **0.000%**（`t05_msb_line_diagnosis_20261021_r01/`）⇒ 两个字节的 MSB 同时恒 0。
- 两种连接器（J11 用 F17、J10 用 W19）、AWB 开/关、手动增益、彩条、白纸、暗行**全部**复现 ⇒ 与场景、白平衡、FPGA 引脚无关。
- 历史回读：`0x3017=0xFF`、`0x3018=0xFF`（D 脚全部设为**输出**）。**尚未回读 `0x301D` / `0x301E`** —— 这正是本方案要补的关键一项。

## 3. 上板实验（待 Wong 允许后执行；单变量、可恢复）

**步骤 1（只读，不改任何寄存器）**：在新 ELF 中回读并打印
`0x3017 / 0x3018 / 0x301D / 0x301E / 0x300A / 0x300B / 0x4741 / 0x4745 / 0x4300 / 0x501F`，同时保留现有 `S3_DIAG6_FP` 指纹与安全转储。
- 判读：**若 `0x301D[3]==1` 或 `0x301E[1]==1` ⇒ 命中 (A)**（D9/D6 被设为寄存器固定值）→ 实验 2 直接修；若全为 0 ⇒ 排除 (A)，进入 (B)/(C) 区分。

**步骤 2（仅在命中 (A) 时）**：只清对应位（`0x301D &= ~(1<<3)` 等），**先记录原值**，随后读同一行样本。
- 预期：蓝 8 位 bit7 与绿 8 位 bit4 由 0.000% 变为正常出现 ⇒ **软件修复成功**，无需动硬件。

**步骤 3（排除 (A) 后，(B) vs (C)）**：用 `0x4745[2:1]` 改变 DVP 输出位的落点（调试选项），**在同一场景、同一 ELF 下**只改这一个寄存器并恢复：
- 若缺失的**通道位仍然固定为蓝 bit7 / 绿 bit4**、只是**物理线号变了** ⇒ 该物理线断 ⇒ **(B) 模块走线/焊点**；
- 若缺失的**通道位随之改变** ⇒ 传感器输出侧问题 ⇒ **(C)**（换传感器/模块）。
- 全过程记录原值、写入值、读回值、恢复值，并保留恢复后的样本，证明实验可逆。

## 4. 边界与限制

- 本方案**未执行任何板卡操作**（Wong 2026-10-21 指示暂不上板）；不写非易失、不改接线、不做电气测量。
- 写测试只针对 `0x301D/0x301E/0x4745` 这类**易失、可恢复**的端口控制寄存器；写前必须回读原值、写后必须恢复并复核。
- 若最终落在 (B)/(C)：颜色验收在缺线修复前**只能判受阻/FAIL**；近似补偿仅作标注清楚的过渡实验（不得作为 G3/G4 依据）。
- 硬件并行路径：厂家返修/更换（只寄模块、不寄 AX7020 板卡），材料见 `report/evidence/S3-CTRL/S3-T05/S3CTRL-20261021-002-handoff-to-codex-stage3.md` 与 Wong 手上的 ALINX 返修单。
