## 2. 结果

### 2.1 连接器信号顺序：与我们的 J11 映射**逐条同序**（第 5 路独立证据）

其 `ddr_ov5640_hdmi.xdc` 的 cmos2 组顺序为
`db[9], sda, db[6], scl, db[7], db[2], href, db[8], db[3], rst_n, db[4], db[5], db[1], db[0], vsync, pclk`
—— 与我们的 `board/stage3/hardware/an5642_j11_cmos2.xdc`（J11 PIN3–PIN18）**顺序完全一致** ✓
（其 FPGA 引脚值是另一块 Alinx 板，A10/B10/C11…，**不适用本板**，故只用于核顺序，不用于核脚）。

### 2.2 8→16 位拼装：与其 `cmos_8_16bit.v` 与厂商原件一致

其源码 `pdata_o <= {pdata_i_d0, pdata_i};`（前一个字节为**高字节**），与厂商 `alinx_ov5640.v` 完全同构
⇒ 再次确认 RGB565 低字节 = {G[2:0],B[4:0]}、**B[4] = 该字节 bit4 = DVP 的 D[6]** ✓

### 2.3 传感器初始化寄存器：与厂商表关键条目**完全一致**

| 寄存器 | 社区表值 | 说明 | 与我们 |
|---|---|---|---|
| 0x4300 | 0x60 | RGB565 | 同 |
| 0x501F | 0x01 | ISP RGB | 同 |
| 0x5001 | 0xA3 | SDE/CMX/AWB on | 同 |
| 0x5580 | 0x06 | saturation on | 同 |
| 0x5583 | 0x40 | | 同 |
| 0x3820/0x3821 | 0x47 / 0x00(640x480 & 480x272) | flip/mirror | 同（我们 0x47/0x00） |
| 0x503D | 0x80 **被注释掉**（`//10'd251: …503d80`） | 彩条测试图 | 与我们用 `0x503D=0x80` 出彩条一致 |
| 分辨率 | 0x3808/0x3809/0x380A/0x380B/0x380C/0x380D 按分辨率改 | | 我们 1280x720 自算 |

⇒ **外部工程的参数配置与我们的厂商表没有实质差异，也没有任何“必须不同配置”才能正常出蓝的做法**。
⇒ 支持既有结论：偏黄不是配置/格式问题，而是 **B[4] 物理丢位**（模块 D6 走线或板侧 F20）。
