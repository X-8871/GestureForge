1. 显示器上有**结构性可辨的画面**（可分辨物体轮廓与箱体上的橙色文字），不是黑屏、不是纯噪声；

## 与已知缺陷的关系（判读，保留不确定性）

- 已定位缺陷：S2MM 帧起始 TUSER(SOF) 从未被认出（SR = `bit4 INT + bit11 FSZ_MORE/SOFLate + ErrIrq`，Halted=0）
  → 预期表现为滚动/撕裂/帧边界不成立；**待 SOF 修复位流上板后复看**。
- 帧缓冲数据已独立验证为**24 位 RGB888**（转换器 565→888 输出，所有字节均为 4 的倍数；
  VDMA `c_s_axis_s2mm_tdata_width=24`），故“16/24 位不匹配造成错位”可排除。
- 偏色与竖直暗带**尚未归因**：可能是真实场景（黄墙/蓝色物体/暗色物体）、传感器镜像/翻转设置
  （`0x3820=0x47`、`0x3821=0x00`）、或帧同步缺失造成的混帧。**未做仪器测量、未做色卡比对**，不作为结论。

## 补充判读（2026-10-20 12:42，JTAG 活性采样，`fb_liveness.log`）

`scripts/stage3_t05/jtag_fb_liveness.tcl` 对同一帧缓冲位置做三次采样（T1→T2 隔 8 s、T2→T3 隔 8 s，
halt→mrd→con 只读）：

- `0x00110C00`、`0x00150C00`、`0x00190C00` 三处在 T1/T2/T3 **逐字节完全相同**；
- 同时 `S2MM SR=0x00010810`（bit4 INT + bit11 FSZ_MORE/SOFLate + FrmCntIrq，Halted=0、Idle=0）。

→ **Wong 看到的“静止画面”是帧缓冲里被冻结的单帧快照**（S2MM 在第一帧后因缺 SOF 不再推进），
**不是实时视频**。这与“帧同步缺失是活画面的唯一阻断”一致；也解释了偏色：
帧起始不成立时 24 位像素的打包相位可能错位，逐像素通道错位会产生“结构可辨但颜色假”的画面。
**结论：先修 SOF，再复看颜色**（颜色缺陷当前不作为独立结论，未用色卡/测试图验证）。
