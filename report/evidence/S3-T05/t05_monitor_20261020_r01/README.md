## 与已知缺陷的关系（判读，保留不确定性）

- 已定位缺陷：S2MM 帧起始 TUSER(SOF) 从未被认出（SR = `bit4 INT + bit11 FSZ_MORE/SOFLate + ErrIrq`，Halted=0）
  → 预期表现为滚动/撕裂/帧边界不成立；**待 SOF 修复位流上板后复看**。
- 帧缓冲数据已独立验证为**24 位 RGB888**（转换器 565→888 输出，所有字节均为 4 的倍数；
  VDMA `c_s_axis_s2mm_tdata_width=24`），故“16/24 位不匹配造成错位”可排除。
- 偏色与竖直暗带**尚未归因**：可能是真实场景（黄墙/蓝色物体/暗色物体）、传感器镜像/翻转设置
  （`0x3820=0x47`、`0x3821=0x00`）、或帧同步缺失造成的混帧。**未做仪器测量、未做色卡比对**，不作为结论。
