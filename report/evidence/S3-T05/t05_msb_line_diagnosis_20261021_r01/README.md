# S3-T05 根因判定：DVP 字节 MSB 无信号（单一数据线）——2026-10-21 21:4x 复核

## 1. 结论

**帧缓冲里「蓝 8 位 bit7」与「绿 8 位 bit4」在全部样本中同时恒为 0**（19 个行样本、共 24,320 像素，置位率 **0.000% / 0.000%**）。
两者分别来自 **DVP 两个字节各自的 MSB**，而在厂商 IP 里两个字节的 MSB 走的是**同一条数据线 `cmos_d[9]`**（IP 取 `cmos_d[9:2]` 当字节）。⇒ 该线**没有信号**是唯一能同时解释这两个缺位的单一故障。

推导线（经 Codex 2026-10-21 更正后与本复核一致）：
- 内存字节序 offset0/1/2 = **B/G/R**；16 位输入字 = {第一字节, 第二字节}；
- 第一字节 = `{g[2:0], b[4:0]}` → 其 MSB = **B[4]** → 字 bit15 → 蓝 8 位 **bit7**；
- 第二字节 = `{r[4:0], g[5:3]}` → 其 MSB = **G[2]** → 字 bit7 → 绿 8 位 **bit4**（G 6 位 ×4 展开后 G[2] 权重 16）；
- 两条 MSB 都等于 `cmos_d[9]`（时分复用两次）⇒ 一线无信号，两位同时丢失。

其中 3 个样本 `maxB` 为 40/112（暗画面），其余为 120 —— 亦即**蓝从未超过 120**，与「蓝 bit7 恒 0」自洽。

## 3. 意义

1. **解释了伪彩**：只补蓝最高位（且用低位硬猜）无法恢复真彩——因为**绿的一位同样丢失**，且猜位在低蓝/暗部会产生 ±128 跳变（Wong 已确认阴影偏蓝、亮部偏黄、明显伪彩，颜色 FAIL）。
2. **定位了故障性质**：这是**单条数据线无信号**，不是格式/配置/白平衡问题；同一模块在 **J10（完全不同 FPGA 引脚）** 上复现同样的双位缺失 ⇒ 指向**模块/传感器侧**。
3. **验收含义**：在缺线未修复前，**颜色验收只能判 FAIL/受阻**；近似补偿仅可作为标注清楚的过渡实验，不能作为 G3/G4 依据。
