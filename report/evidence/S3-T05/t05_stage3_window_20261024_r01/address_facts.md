# 阶段3 视频通路静态地址事实（2026-10-24 板级窗口实测）

- 目的：为阶段4 RAW 缓冲选址 `[0x12000000,0x12C08000)` 是否与**阶段3** 相交提供**部署事实**（只读回读，不改变任何配置）。
- 来源：本窗口实测寄存器回读（`addr_map_final2.txt`、`addr_scan_final.txt`、`mm2s_scan_final.txt`）与应用自身 UART 诊断。
- 部署：无补偿 SOF `7cb33068…` + `an5642_j11cmos2_v10_read.elf` `1457cda4…`（实时彩色）。

## 3. 结论（对应索取项）

1. **采集帧缓冲基址集合**：`{0x00110C00}`（活动部署；**单缓冲**）。**无静态编译期保证**——地址由应用运行期
   通过 `dispCtrl.framePtr[curFrame]` 分配；**不同应用会不同**：v11 冻结应用为 `0x00114C00`（其 UART `S3_DIAG11_HALT ... FB=0x00114C00`）。
2. **显示/送显缓冲基址与大小**：MM2S 帧地址 = **`0x00110C00`（与采集完全相同）**，`stride 0x0F00`、`720×3840 = 0x2A3000` 字节。
3. **DMA 基址**：`ADDR_S2MM=0x00110C00`、`ADDR_MM2S=0x00110C00`、`STRIDE_S2MM=STRIDE_MM2S=0x00000F00`、
   `HSIZE=0x00000F00`、`VSIZE=0x000002D0`（均为**运行期回读**，非静态常量）。
4. **是否有阶段3 缓冲 ≥ `0x10000000`**：**实测没有**。观测到的全部阶段3 帧地址为 `0x00110C00`（v10 实时）与
   `0x00114C00`（v11 冻结），**均远低于 `0x10000000`**，故与阶段4 候选区 `[0x12000000,0x12C08000)` **不相交**。
   **注意**：该结论是**部署实测事实**，不是链接期静态保证；若阶段4 需要硬保证，应由分配逻辑/链接脚本层面确认（阶段4 自决）。
5. **采集与显示是否共用同一帧缓冲**：**共用**（已实测，不再是"可能"）——`S2MM @0x430100AC = 0x00110C00`
   与 `MM2S @0x4300005C = 0x00110C00` 相同，即**原始画面直通**：采集写入的缓冲就是显示读取的缓冲，**单缓冲、无环形队列**。

## 4. 边界

- 本文件只给**部署事实与实测值**；不替代阶段4 的地址规划与 G0，也不构成对阶段4 的任何批准。
- 地址随应用/链接布局变化：**任何消费方在使用前必须运行期回读**（既有规则：禁止硬编码旧地址）。
