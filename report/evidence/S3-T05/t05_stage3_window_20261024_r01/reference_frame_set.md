## 2. 格式 / 字节序 / 几何 / 坐标口径

- 分辨率 **1280×720**；每行 **3840 字节**（1280 px × 3 B）；`stride = 0x0F00 = 3840`。
- **内存字节序 = B, G, R**（每像素 3 字节：offset0=B、offset1=G、offset2=R）——与归档 subset-converter 网表
  及阶段5/6 既有口径一致；**与传感器 RGB565 字内字段、与模型 RGB888 语义不能直接混同**。
- 帧基址 = `ADDR_S2MM`（本帧为 `0x00114C00`，**v11 冻结应用的分配**；实时部署 v10 为 `0x00110C00`，见 `address_facts.md`）；
  行地址 = `base + y × stride`（**运行期回读，禁止硬编码**）。
- 原图坐标口径：`(x, y)`，`x∈[0,1280)`、`y∈[0,720)`，原点在左上；`row_yN.bin` 对应 `y=N` 整行（已验证与整帧切片逐字节一致）。
