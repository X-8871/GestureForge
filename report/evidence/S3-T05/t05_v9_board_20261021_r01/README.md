## 2. 回读结果：**配置侧假设被排除**

```
S3_DIAG9_PAD=3017=0xFF 3018=0xFF 301D=0x00 301E=0x00 300A=0x56 300B=0x40 4741=0x00 4745=0x00 4300=0x60 501F=0x01 S3_DIAG9_D9SEL=0 D6SEL=0
```

| 寄存器 | 实测 | 含义 | 结论 |
|---|---|---|---|
| `0x3017` | `0xFF` | FREX/VSYNC/HREF/PCLK + D[9:6] 全部**输出使能** | D 脚没被禁用 |
| `0x3018` | `0xFF` | D[5:0] 输出使能 | 同上 |
| **`0x301D`** | **`0x00`** | D[9:6] output **select** = 0 ⇒ **正常数据通路**（不是寄存器固定值） | **软件覆盖假设排除** |
| **`0x301E`** | **`0x00`** | D[5:0] output select = 0 ⇒ 正常数据通路 | 同上 |
| `0x4741` | `0x00` | 测试图案关闭 | 非测试图案干扰 |
| `0x4745` | `0x00` | DVP 顺序 = 默认 `D[9:0]`、位序正常 | 非顺序/位序配置 |
| `0x4300`/`0x501F` | `0x60`/`0x01` | RGB565 + ISP RGB | 与既有结论一致 |

传感器侧另有对照事实：`0x3017/0x3018` 被厂商 init 表写 `0xff`（D 脚全输出），而 `0x301D/0x301E/0x4741/0x4745` **不在 init 表**、保持 POR 默认 ⇒ 从未被配置成"固定值/调试顺序"。

## 4. 综合结论（根因收敛，且不在软件）

排除项（各有独立证据）：
1. **配置/软件**：`0x301D/0x301E` = 正常数据通路、D 脚输出使能全开、测试图案与位序均为默认（本次回读）；
2. **RTL/映射**：五路映射证据 + J10/J11 两份 io_placed 逐条核对 + 转换器与显示通道网表分析（历史证据）；
3. **FPGA 引脚**：同一模块在 J11（D9→F17）与 J10（D9→W19）复现同样双位缺失；
4. **场景/白平衡**：AWB 开关、手动增益 3.5×、彩条、白纸、暗行全部复现。

⇒ 唯一自洽解释：**DVP 字节 MSB 的物理链路（模块 J3 pin3 `CMOS2_D9` → 传感器 D9 输出）无信号** —— 属**模块/传感器侧硬件缺陷**，**没有软件修复**。
