## 2. 判据适用性更正（重要，如实记录）

- 既有"位完整性/缺位签名"判据的前提是**明亮目标**（彩条白条 `G8>=248`、`B8>=240`、黑条负样本）。本轮转储的是**近全黑真实场景**帧，`maxB=0` 属暗场正常表现，**不构成缺位复现**。
- 因此本轮**不得**引用该判据判定"缺位/故障"；先前以该判据字面结果推断"符合缺位签名"的表述**在此更正为不适用**。
- 结论：**机器侧可确认的是**部署身份（间接）、运行期地址/配置、帧活性与 VDMA 状态；**真彩画面仍需人工目视确认**（明亮有纹理场景），缺位类判据须在**明亮/彩条**帧上运行才有意义。
