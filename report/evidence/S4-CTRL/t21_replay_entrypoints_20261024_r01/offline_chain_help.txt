usage: run_s4b_offline_chain.py [-h] --run-id RUN_ID [--samples SAMPLES]
                                [--sample-indices SAMPLE_INDICES] [--gcc GCC]
                                [--contract CONTRACT] [--tolerance TOLERANCE]
                                [--expected-contract-sha256 EXPECTED_CONTRACT_SHA256]

S4-B 离线集成链驱动（冻结 heads -> C 解码 -> s2bu 帧 -> 对拍）

options:
  -h, --help            show this help message and exit
  --run-id RUN_ID       新运行标识；evidence/<run_id> 必须不存在
  --samples SAMPLES     使用前 N 个冻结样本（1..3）
  --sample-indices SAMPLE_INDICES
                        逗号分隔的冻结样本索引（最多 3 个，如 36,56,102 用于多框/跨类/NO_HAND
                        覆盖）；缺省取前 --samples 个
  --gcc GCC             gcc 路径
  --contract CONTRACT   S4-A 契约相对路径
  --tolerance TOLERANCE
                        score/xyxy 绝对误差上限
  --expected-contract-sha256 EXPECTED_CONTRACT_SHA256
                        期望的 S4-A 契约 SHA-256；缺省取现场读出值（不硬编码历史哈希）
