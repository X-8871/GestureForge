# DDR 位完整性 / 保持测试方案（ddr_bit_test_plan_20261027_r01，r02 更正版）

> 定位：**查根因**用，不是改验收判据；执行并入 4-D bring-up 窗口，**不单开窗**。
> 背景：窗口 B r02 候选区 6 字节差异（6 处各清 1 bit）；地址归属 = `NEITHER_ACCOUNTED`。

## 0. 更正记录（r01 → r02，必须留痕）
- **r01 错误**：正文写测试区 `0x01AE0000–0x01B00000`，但同段非冲突证明描述的是 arena 尾部空档 `0x11ADADB8–0x12000000`；**两者不一致**——`0x01AE0000` 位于 weights(`0x005A12FC`) 与 arena(`0x10000000`) 之间的大空档，**不在**所证空档内。
- **性质**：文档内部矛盾（地址笔误），非测量数据错误；**r01 未执行任何写入**，故无硬件影响。
- **r02 定稿**：测试区改为 **`0x11ae0000–0x11b00000`（128 KiB）**，与"arena 尾部空档"证明一致。
- 复核：`0x11ae0000+0x20000 = 0x11b00000 < 0x12000000` ✔；`0x11ae0000` 64 B 对齐 ✔；不与 head26 窗（止于 `0x11ADADB8`）重叠 ✔。

## 1. 测试区与非冲突逐项证明
**定稿测试区**：`0x11ae0000–0x11b00000`，**131,072 B**，64 B 对齐。

| 已登记对象/区间 | 范围 | 与测试区关系 |
|---|---|---|
| tensor | `0x10000000–0x1007EC00` | 在其后，不重叠 ✔ |
| feature | `0x11000000–0x11ADADB8` | 止于 `0x11ADADB8` < `0x11ae0000` ✔ |
| head13 | `0x11A46100–0x11A474AE` | 不重叠 ✔ |
| head26 | `0x11AD5E80–0x11ADADB8` | 止于 `0x11ADADB8` < `0x11ae0000` ✔ |
| arena 整体 | `0x10000000–0x12000000` | 测试区**在其尾部空档内**（`0x11ADADB8` 之后至 `0x12000000`）✔ |
| raw_frame（候选区） | `0x12000000–0x12C00000` | 测试区**完全在候选区之外** ✔ |
| raw_meta | `0x12C00000–0x12C08000` | 不重叠 ✔ |
| weights | `0x00100000–0x005A12FC` | 不重叠 ✔ |
| 2B DDR 地址段 | `0x00100000–0x3FF00000` | 测试区在段内 ✔ |

结论：**测试区不与任何已登记对象重叠，且位于候选区之外**；arena 为 PS 应用 `.s2b_tensor_ddr`（NOLOAD）区域的未登记尾部。

## 2. 图样（4 种）
`0x00`｜`0xFF`｜`0xAA/0x55` 相邻字节交替｜**walking-1 稀疏版**（每 64 B 仅 1 bit 置 1，64 B 内 512 位循环）。

## 3. 读时序
T0 写后立即｜T1 +30 s｜T2 +60 s｜T3 +5 min（保持测试；窗口不足 ⇒ 独立长跑项）。

## 4. 写入纪律与恢复方案（授权条件，逐条）
1. **写入前先只读快照**：整 128 KiB dump → `ddr_test_snapshot.bin` + SHA-256 + 真实退出码；
2. 每次图样写入**严格限定 128 KiB**：写入前断言 `addr ∈ [0x11ae0000,0x11b00000)` 且 `addr+len ≤ 0x11b00000`，越界即停；
3. 每图样：写 → T0/T1/T2 整区读回（另存 `readback_<pattern>_T<n>.bin`）→ 逐字节比对 → 记录差异；
4. **收尾按快照恢复**：`mwr -bin -file <snapshot> 0x11ae0000 32768`（32768 字 = 131,072 B），随后**整区读回并与快照逐字节比较，diff 必须为 0**；diff≠0 ⇒ 立即停、保留现场、报 lead；
5. 每个动作落真实退出码；不写测试区之外任何字节；不烧 QSPI；不发独立 `stop`。

## 5. 判定
- T0–T2 全部逐字节相等 ⇒ `DDR_BIT_TEST_PASS`；
- **任一处单 bit 差异 ⇒ `DDR_BIT_ERROR_SUSPECTED`（不记 PASS）**，报 **errors/bytes/time** + 地址/位位置；
- T3 失败 ⇒ `DDR_RETENTION_SUSPECTED`（独立结论）。

## 6. 先后与预算（并入 4-D bring-up，60 min 申请）
bisect 6–8 → DDR 图样 T0–T2 5–8 → M4-a 6 → M4-b 10 → 剩余做 M3 复检 12 / T3 5（可顺延为长跑/独立项）。
