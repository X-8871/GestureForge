## 4. 6-C：确定性测试矩阵

每行都要求预期状态、预期动作数、时间边界、实际日志及断言：

| 用例 | 必须证明 |
|---|---|
| 每类稳定输入 | 在冻结条件满足后触发对应动作 |
| 持续保持与冷却后保持 | 按冻结规则唯一触发，不发生无意重复 |
| 手离开再出现 | 达到重获条件后可再次触发 |
| 两类快速切换/短暂抖动 | 未达到稳定条件不触发，状态转换可复算 |
| 多目标/同分/目标跳变 | 选择和跟踪确定，避免跨目标拼稳定窗口 |
| NO_HAND / 场景未知 / 低分 | 分开计数，不用零框掩盖未知误识别 |
| TIMEOUT / ERROR / DROPPED / stale | 无不当动作，错误可观测并恢复 |
| 重复、倒序、缺帧、重启帧号 | 不重复计票，不错误延续旧会话状态 |
| 时间等于阈值、前后1个计时单位 | 包含/不包含边界与G0一致 |
| 无新结果但时间持续前进 | 失踪与超时正常生效 |
| 动作失败/未观察/重复ACK | 不虚报成功，计数和重试符合规格 |

离线通过名称为“状态机确定性测试PASS”。脚本直接喂OK/NO_HAND不能支撑摄像头未知误接受率。

## 5. 6-D：无摄像头的两级联调

一级：脚本结果→真实PS状态机→HDMI动作。验证日志与实际画面/状态对应，动作失败也留证。
二级：独立图片/视频序列→板上实际预处理/推理→PS状态机→HDMI。不能由脚本强制给出正确类别；记录模型误识别和动作结果。

1. 用独立留出素材，按人员/录制会话区分，保留序列时间和输入哈希；不把同一段循环200次算200个独立样本。
2. 为已知手势、未知手势、无手、运动背景等预定义场景与预期。
3. 回放输入和检测输出同帧关联，失败定位到模型、时序、状态机或执行层。
4. 回放的时间缩放/帧率必须声明；加速回放只能验证相应时序条件，不能冒充30分钟物理运行。
5. 可进行≥30分钟真实时间的回放稳定性实验，标注“回放输入下”；摄像头曝光、真实运动与现场误触仍未覆盖。

## 6. 6-E：正式摄像头验收与统计

阶段3—5相关条件完成、G0指标获批后执行。现有阈值表明确未冻结，以下是待按原计划落实的建议，不是本文新增批准：

- 已知有效动作成功率≥90%。草案建议≥50次、每类≥10次，推荐≥100次；正式样本数先冻结。分母为全部预定义试验，超时、错误动作、重复触发、执行失败及未观察不能剔除以提高成功率。
- ≥200个独立未知输入，样本级误接受率≤5%。一个样本出现任意已提交动作即计误接受，执行失败不豁免；恰200样本时点估计最多10个，但这不证明95%置信上界≤5%。
- 无有效手势连续≥30分钟误动作≤1次。按动作提交计数，记录完整时段，不裁剪成功片段。
- 置信区间作为附加统计；若要求区间界限也达标，G0先确定样本设计与通过标准，不能测试后临时改变。
- 输入按人/场景/录制会话区分独立性；200张相邻视频帧不能自动当200次独立未知试验。
- 保留真实输入、检测输出、状态/动作日志、连续视频及所有失败，报告每类/每环境结果。

正式测试前固定阈值。若失败需要调参，使用开发/验证数据，之后在新的或未使用的保留集重新验收。
