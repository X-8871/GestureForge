## 6. 停止条件（出现即停，保全证据，按安全状态恢复）

1. 无有效输入却连续动作；
2. 状态机卡死（约定无进度超时：同一状态连续 ≥300 s 无有效进展）；
3. 无法解释的旧帧触发（`trigger_frame_id` 早于已处理水位）；
4. 日志丢失或计数不自洽；
5. OOM / NaN / Inf / 数据损坏；
6. JTAG/COM4/HDMI 出现他方并发使用的迹象。

停止后：保全原始日志与视频、记录板上最终状态、按冻结的安全状态恢复（退出交互、保持显示默认态），并以**新 RunId** 重测，不得就地续跑或继续计作成功运行。
