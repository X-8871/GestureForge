怎么用

  • 点击“启动摄像头”，选择真实手势后让手进入取景框。
  • 点击“同帧跑三模型”，每个卡片会显示最高分框和延迟。
  • 按真实手势选择框标记“正确 / 错误”；统计保存在当前浏览器。

边界

卡片中的“人工样本估计”不是官方 test mAP。no_hand 目前是阶段一非阻断诊断项；官方 no_gesture 不会被改写成无手类别。
